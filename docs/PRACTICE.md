# Что нужно выполнить самостоятельно

Отмечать галочки только после собственного запуска.

- [ ] Установить Python и запустить локальный \`demo_app.py\`
- [ ] Проверить \`/health\` (код 200) и \`/fail\` (код 503)
- [ ] Проверить доступный и закрытый TCP-порт
- [ ] Запустить \`python -m unittest discover -s tests -v\`
- [ ] Записать результат проверки в JSONL и объяснить поля
- [ ] Самостоятельно изменить \`--expected\` и понять результат
- [ ] Создать настоящий учебный тикет в своей Jira (если есть доступ)
- [ ] Дописать в README скриншоты своего запуска с удалёнными секретами

**Вопрос для собеседования:** чем отличается «порт открыт» от «HTTP работает правильно»?
