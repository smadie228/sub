# QA-чеклист Service Checker — KAN-6

**Проект:** [Service Checker](../README.md) — учебная Python CLI-утилита для проверки HTTP и TCP.  
**Задача:** [KAN-6 в Jira](https://voldan65.atlassian.net/browse/KAN-6) (для просмотра может потребоваться доступ).  
**Тип:** чеклист тестирования. Фактические результаты зафиксированы в [отчёте от 09.11.2026](QA_EXECUTION_2026-11-09.md).  
**Проверка исходников:** 09.11.2026. **Выполнение тест-кейсов:** подтверждены TC-01–TC-09 (9/9 PASS); TC-10 и TC-11 не применяются к текущему демо. После исправления предупреждения — 8/8 автотестов PASS.

## Подготовка

1. Установить Python 3.10+.
2. В первом терминале из корня проекта запустить `python demo_app.py`.
3. Во втором терминале выполнять команды из таблицы.
4. Для каждого теста заполнить фактический результат, дату, версию Python и ОС. Ставить PASS только после собственного запуска.

Демо-сервер использует `127.0.0.1:8000`: маршрут `/health` реализован с HTTP 200, `/fail` — с 503, все остальные — с 404. В фактическом прогоне использован такой же обработчик на случайном свободном порту `127.0.0.1`; результаты приведены отдельно в [QA-отчёте](QA_EXECUTION_2026-11-09.md). В примерах проверяются только локальные ресурсы.

**Важно:** 503 на маршруте `/fail` — намеренное поведение демо, не найденный дефект. Успех проверки означает совпадение фактического HTTP-кода с параметром `--expected`, а не обязательно работоспособность бизнес-функции.

## Автотесты и запись фактов

Запустить из корня проекта:

```powershell

```
