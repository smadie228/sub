# Учебный Jira-тикет: INC-DEMO-001

**Статус:** Пример, не настоящий тикет Jira.

**Тип:** Incident  
**Тема:** Демонстрационный HTTP-сервис отвечает 503 вместо 200  
**Приоритет:** Medium (учебное допущение)  
**Окружение:** локальный Python HTTP-сервер на 127.0.0.1:8000

## Шаги воспроизведения

1. Запустить `python demo_app.py`.
2. Выполнить `python service_check.py http http://127.0.0.1:8000/fail`.
3. Получить FAIL / HTTP 503. Для `/health` — HTTP 200.

## Ожидаемое поведение

Проверка `/health` должна возвращать 200. На `/fail` намеренно реализована ошибка, поэтому этот адрес не является здоровым endpoint.

## Выполненная диагностика

- Проверено TCP-подключение к порту 8000.
- Сравнены коды ответов `/health` и `/fail`.
- Причина: маршрут `/fail` специально реализован с кодом 503 для практики.

## Решение и коммуникация

Инцидент **симулирован**. В реальном случае передал бы результаты на L2/разработчику, проверил исправление и обновил Jira-тикет. Не утверждаю, что работал с реальной Jira Cloud по этому примеру.
