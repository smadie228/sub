# Service Checker — учебный проект для IT Support

Небольшая утилита на Python для проверки HTTP-сервисов и TCP-портов. Делаю её как практику по технической поддержке и диагностике сетевых проблем. Это учебный проект, а не коммерческий сервис.

## Что умеет

- проверять HTTP-код ответа;
- проверять доступность TCP-порта;
- показывать понятную ошибку и время ответа;
- выводить результат в JSON и записывать его в JSONL-журнал;
- работать без сторонних Python-библиотек.

## Запуск

Нужен Python 3.10+.

Терминал №1 — тестовый сервис:

~~~bash
python demo_app.py
~~~

Терминал №2 — проверки:

~~~bash
python service_check.py http http://127.0.0.1:8000/health
python service_check.py http http://127.0.0.1:8000/fail
python service_check.py tcp 127.0.0.1 8000
python service_check.py --json --log results.jsonl http http://127.0.0.1:8000/health
~~~

Код завершения: 0 — всё хорошо; 2 — проверка не прошла. Проверяйте только свои ресурсы или ресурсы, на проверку которых у вас есть разрешение.

## Тесты
